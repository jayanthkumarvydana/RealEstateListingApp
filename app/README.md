# Real Estate Listings with Map View 📍🏠

## Overview
The **Real Estate Listings with Map View** is an Android application that allows users to browse, post, and manage real estate properties efficiently. The app provides both **list-based** and **map-based** property exploration, helping users make better decisions based on **location, price, and facilities**.

This project is developed as part of an academic submission and demonstrates the use of **modern Android development practices** using **Jetpack Compose**, **Firebase**, and **Google Maps**.

---

## Features ✨

- User Registration & Login
- Add and manage property listings
- View all properties in a list
- View properties on Google Maps with markers
- Filter properties by place, price, and type
- Save favorite properties locally
- Profile management (update name and zip code)
- About Us & Contact Us section
- Secure logout with session clearing

---

## Technologies Used 🛠️

- **Kotlin**
- **Jetpack Compose (Material 3)**
- **Firebase Realtime Database**
- **Google Maps SDK**
- **Maps Compose**
- **SharedPreferences**
- **Coil (AsyncImage)**

---

## Application Modules 📱

- **Home Screen** – Displays all properties with filters
- **Add Property Screen** – Allows users to post new properties
- **Map View Screen** – Shows all properties as markers on the UK map
- **My Listings Screen** – Displays properties added by the logged-in user
- **Profile Screen** – View and update user profile details
- **About & Contact Screen** – App and developer information

---

## Data Storage 📂

- **Firebase Realtime Database**
    - Stores user data and property listings
    - Structured under user identifiers for scalability

- **SharedPreferences**
    - Stores login session
    - Stores user profile details for quick access

---

## Permissions Required 🔐

- Internet Access
- Location Access (for map-based property viewing)

---

## How to Run the Project ▶️

1. Clone the repository
2. Open the project in **Android Studio**
3. Add your **Google Maps API key** in `AndroidManifest.xml`
4. Connect Firebase to the project
5. Run the app on an emulator or physical device
